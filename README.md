# 🚀 DSA Tracker & Interview Practice Platform

A full-featured, responsive Data Structures & Algorithms (DSA) problem tracker and interview practice platform built with **React**, **TypeScript**, and **Vite**.

---

## ✨ Features

- 🔤 **Pre-loaded Problem Sheets**: Includes 25 Easy String problems categorized into structured learning levels with direct LeetCode links.
- 🟢🟡🔴 **Nested Difficulty Tabs**: Explore problems by Easy, Medium, and Hard tiers under each core concept.
- 🏢 **Company-Specific Interview Sheets**: Dedicated target sheets for top tech companies including **Google**, **Amazon**, **Microsoft**, **Meta**, **Apple**, **Netflix**, **Uber**, and **Adobe** with vector SVG brand logos.
- 🎯 **Smart Daily Practice Plan (Spaced Repetition)**: Uses retention memory decay modeling ($R(t) = \exp(-t/S)$) to automatically recommend daily revision targets.
- ⏱️ **Code Complexity Evaluator**: Real-time Big-O Time & Space complexity analysis for C++, Java, Python, and JavaScript solutions.
- 👤 **Multi-User Account Support**: Switch user profiles to save and track individual progress separately in local storage.
- 🖤 **Multi-Theme Support**: Toggle between **Pure OLED Black Night Mode (`#000000`)**, **Dark Slate**, and **Clean Light Mode**.
- 💻📱 **Fully Responsive**: Designed for full-screen laptop displays with responsive grids and 100% mobile compatibility.

---

## 🛠️ Technology Stack

- **Frontend Framework**: React 18 + TypeScript
- **Build Tool**: Vite
- **Icons**: Lucide React
- **Styling**: Vanilla CSS with HSL variables & OLED Dark themes

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/sampath300-dot/dsa-tracker.git
cd dsa-tracker
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Build for Production
```bash
npm run build
```
